Briefly

A focused workspace for turning videos into briefs

Briefly is a private Ruby on Rails workspace that turns public YouTube videos into structured, source-faithful briefs. It queues analysis, stores completed briefs, and makes them easy to revisit in a personal library.

I built the main application flows, asynchronous processing, retryable failure handling, persistent brief storage, and password-gated workspace access. The project was developed with AI assistance, but I reviewed and refactored the implementation and own the architecture and engineering decisions.

Ruby on Rails · SQLite · Solid Queue · Gemini · asynchronous processing

Available locally; there is no public deployment or demo.
