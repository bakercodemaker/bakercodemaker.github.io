Briefly

A focused workspace for turning videos into briefs

Briefly is a private, single-owner Ruby on Rails workspace that turns public YouTube videos into structured, source-faithful briefs. It persists analysis requests, processes them asynchronously with Gemini, and stores completed briefs in a small personal library.

I built the main Rails flows, durable background processing, retryable failure handling, password-gated workspace access, and the Gemini integration seam. The project was developed with AI assistance, but I reviewed and refactored the implementation and own the architecture and engineering decisions.

Rails 8.1 · SQLite · Solid Queue · Tailwind CSS · Gemini API · automated tests

Available as a downloadable local project; there is no public deployment or demo.
